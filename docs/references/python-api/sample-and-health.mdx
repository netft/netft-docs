# Samples and health

<ApiType manifest={pythonManifest} symbolId="pynetft.Sample" />

`wrench` is the read-only six-value `(Fx, Fy, Fz, Tx, Ty, Tz)` property. `received_at_ns` is a host monotonic timestamp.

`python_queue_dropped_count` is application-delivery pressure, not UDP packet loss. `Health.empty()` constructs a stopped zero-counter snapshot for initialization and testing.

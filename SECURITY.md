# Security Policy

## Supported versions

Security fixes are provided for the latest published site and the `main` branch once this repository is released. Until then, reports apply to the reviewed local source.

## Report a vulnerability

Do not open a public issue or pull request for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/netft/netft-docs/security/advisories/new) so maintainers can assess the report before disclosure.

Include the affected page or build component, reproducible steps, expected impact, and suggested mitigation when available. Remove sensor addresses, private network details, credentials, recordings, and personal data.

For a vulnerability in a Net F/T application, SDK, or robotics integration, report it through the owning repository's security policy. This repository does not own those runtime or release artifacts.
